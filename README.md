## 📌 Project Overview

A Flappy Bird-style arcade game developed in **Unity 2D** and **C#**, featuring a custom fantasy-inspired theme and original pixel-style assets.

This project focuses on recreating core physics-based arcade mechanics while combining custom game programming with original pixel art design.

## 🛠️ Tech Stack & Game Architecture

- **Engine:** Unity (2D Physics & Collision System).
- **Programming Language:** C# (Player controller, procedural obstacle spawner, score manager, and state transitions).
- **Art & Visuals:** Original pixel-art sprites and fantasy environment design.

```text
[ Player Input (Click) ] ──► [ Rigidbody2D Impulse ] ──► [ Obstacle Spawner & Collision ] ──► [ Score / Game Over State ]
```

## 🎨 Visual Concept & Gameplay Mechanics
Instead of traditional birds and pipes, the game introduces an original fantasy aesthetic:
- 🚗 Player Character: A flying car controlled via classic tap-to-fly physics (Left Click).
- 🐍 Dynamic Obstacles: Serpent-like enemies spawned with randomized vertical gaps.
- 🏰 Environment: Fantasy castle backdrop with progression-based score tracking and instant restart on Game Over.

## 🚀 How to Run

1. Clone the repository:
```bash
git clone https://github.com/renatosaldiviap/flappy-bird-clone-unity-game.git
```
2. Open the project folder using Unity Hub.
3. Load the main game scene inside the Unity Editor and press Play.
